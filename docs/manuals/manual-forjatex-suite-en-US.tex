\section{What is ForjaTeX App Suite}
\textbf{ForjaTeX App Suite} is the lightweight central launcher for the ForjaTeX ecosystem. It detects installed applications on your machine, launches them in one click, and downloads updates directly from \textbf{GitHub Releases}.

\section{Installing, Launching, and Updating Apps}
\begin{enumerate}
  \item Each card displays the current or latest version, dedicated app icon, summary, and primary action button (\textbf{OPEN}, \textbf{INSTALL}, or \textbf{UPDATE}).
  \item Use the \textbf{INSTALLER} selector in the toolbar to choose between \textbf{.MSI (Default)} — installed via \texttt{msiexec /passive} — and \textbf{.EXE (NSIS)}.
  \item While downloading, a live progress bar shows megabytes downloaded out of total size and completion percentage.
  \item Use the \textbf{...} menu on any card to reinstall or view release notes.
\end{enumerate}

\section{Suite Self-Update}
When a newer version of \textbf{ForjaTeX App Suite} is published in \texttt{suite-manifest.json}, a top banner displays \textbf{UPDATE \& RESTART}. Clicking it downloads the new installer, updates silently, and relaunches the Suite automatically.

\section{Language, Theme, and Support}
\begin{itemize}
  \item \textbf{Language:} Automatically detected from your OS and switchable anytime between \textbf{PT-BR} and \textbf{EN} in the top bar.
  \item \textbf{Theme:} Toggle Light/Dark mode via the Sun/Moon button.
  \item \textbf{Support \& Feedback:} Click \textbf{SUPPORT} to donate via Pix/PayPal or send feature requests and bug reports directly to \texttt{forjatex.com.br}.
\end{itemize}

\section{Glossary}
\begin{description}
  \item[Manifest JSON (\texttt{suite-manifest.json})] Metadata file hosted on GitHub Releases listing the latest versions and installer URLs.
  \item[MSI (Windows Installer)] Standard Microsoft installer format executed via \texttt{msiexec}.
  \item[NSIS (.exe)] Lightweight per-user installer (\texttt{\%LOCALAPPDATA\%}).
\end{description}
