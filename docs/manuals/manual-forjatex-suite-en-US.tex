\section{What is ForjaTeX App Suite}
\textbf{ForjaTeX App Suite} is the lightweight central launcher for the ForjaTeX ecosystem. It detects installed applications on your machine, launches them in one click, and downloads updates directly from \textbf{GitHub Releases} without requiring accounts or subscriptions.

\section{Installing, Launching, and Updating Apps}
\begin{enumerate}
  \item Each card displays the current or latest version, dedicated app icon, summary, and primary action button (\textbf{OPEN}, \textbf{INSTALL}, or \textbf{UPDATE}).
  \item Use the \textbf{INSTALLER} selector in the toolbar to pick the best format for your system:
  \begin{itemize}
    \item \textbf{Windows:} \textbf{.MSI (Default)} via \code{msiexec /passive} or \textbf{.EXE (NSIS)}.
    \item \textbf{Linux:} \textbf{.DEB (Ubuntu/Debian)} via \code{pkexec dpkg -i} or portable \textbf{.AppImage} installed to \code{\~/.local/bin}.
  \end{itemize}
  \item While downloading, a live progress bar shows megabytes downloaded out of total size and completion percentage.
  \item Use the \textbf{...} menu on any card to reinstall or view release notes.
\end{enumerate}

\section{Suite Self-Update}
When a newer version of \textbf{ForjaTeX App Suite} is published in \code{suite-manifest.json}, a top banner displays \textbf{UPDATE \& RESTART}. Clicking it downloads the new installer, updates silently, and relaunches the Suite automatically.

\section{Language, Theme, and Support}
\begin{itemize}
  \item \textbf{Language:} Automatically detected from your OS and switchable anytime between \textbf{PT-BR} and \textbf{EN} in the top bar.
  \item \textbf{Theme:} Toggle Light/Dark mode via the Sun/Moon button.
  \item \textbf{Support \& Feedback:} Click \textbf{SUPPORT} to donate via Pix/PayPal or send feature requests and bug reports directly to \code{forjatex.com.br}.
\end{itemize}

\section{Glossary}
\begin{description}
  \item[Manifest JSON (\code{suite-manifest.json})] Metadata file hosted on GitHub Releases listing the latest versions and installer URLs for Windows and Linux.
  \item[MSI / NSIS (.exe)] Standard Windows installer formats (\code{msiexec} and per-user NSIS).
  \item[DEB / AppImage] Native Debian/Ubuntu package format (\code{.deb}) and universal portable Linux executable (\code{.AppImage}).
\end{description}
